# Baselines

`agent_sft` baseline / re-measure report output directory. The file is generated by cross-seed aggregation of [`aggregate_seeds.py`](../aggregate_seeds.py) from [`play/evals/runs/index.jsonl`](../../../evals/runs/index.jsonl); this directory is submitted to git to facilitate PR review of historical baseline evolution.

## Reading rules

|Directory/File|Base|What can it say|What can’t it say|
|---|---|---|---|
|`qwen2.5-7b-vs-32b.md`|Qwen2.5-7B / 32B|v1 baseline before training|qwen3.5 current effect|
|`phase5-3model-comparison.md`|Qwen2.5 base / SFT / 32B|v1 closing number: 57.3% gap closure|qwen3.5 current effect|
|`qwen3_phase3/`|qwen3.5:9b / placeholder / qwen3.6:27b|qwen3 evaluation pipeline can still run after migration|SFT adapter effect; placeholder is not adapter|
|`qwen3_bf16_clean/`|qwen3.5:9b/placeholder|in-dist vs held-out layered caliber|real adapter gain; GGUF deploy still blocked|

## v1 Phase 1（Qwen2.5-7B vs 32B）

|File|When to run|Estimation|
|---|---|---|
|`qwen2.5-7b-vs-32b.md`|After pulling two ollama models |80 runs ≈ 3-4h on M4 Pro 48GB|

Prefix:

```bash
ollama pull qwen2.5:7b
ollama pull qwen2.5:32b   # skip if already present
```

See `python play/agent_sft/eval/run_baseline.py --help` + `python play/agent_sft/eval/aggregate_seeds.py --help` (the default value is Phase 1 configuration) for all flags of batch running/reporting/smoke debugging.

## v1 Phase 5（base 7B vs SFT 7B vs 32B）

When retesting, append the ollama tag after SFT to `--models` and run again. The aggregator will automatically display the 3 models side by side:

```bash
python play/agent_sft/eval/run_baseline.py --models qwen2.5:7b qwen2.5:32b agent-sft-qwen:latest
```

## Notes after migration to qwen3.x

|Point|Description|
|---|---|
|Default model|`run_baseline.py` has defaulted to `qwen3.5:9b` / `qwen3.6:27b`|
|placeholder|`agent-sft-qwen-3` is currently `FROM qwen3.5:9b`, which can only verify the pipeline, not the adapter|
|27B timeout|The agent path of qwen3.6:27b on M4 Pro may exceed the default 600s; use `AGENT_ENGINE_RUN_TIMEOUT` to lengthen it if necessary|
|Real SFT effect|Look at `train/eval_smoke.py` or future MLX server path in the short term; don’t use placeholder numbers to draw conclusions before Ollama GGUF is fixed|
